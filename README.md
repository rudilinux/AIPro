# AIPro

Lightweight Local AI Coding CLI for Linux.

AIPro adalah tool Bash CLI ringan untuk memaksimalkan AI lokal melalui llama-server jaringan LAN, fokus membantu coding workflow seperti:

- Python
- Bash
- Svelte / SvelteKit
- Web Development
- Refactor
- Debugging
- Code Generation

## Kenapa AIPro?

- Ringan & cepat
- Bash native
- Linux first
- Local / LAN first
- Tidak bergantung cloud
- Cocok laptop spek rendah

## Fitur

- ask
- code
- fix
- patch
- context
- project scan
- multi-agent coding mode
